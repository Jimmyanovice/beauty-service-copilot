## 软件回归

`tests/`包含原项目完整软件测试。测试使用模型替身和隔离SQLite，检查时点、风险、结构化输出、声明约束、缓存、队列和人工流程，不需要云端模型。

```powershell
.\.venv\Scripts\python.exe -B -X utf8 -m pytest -q -p no:cacheprovider tests
```

原本地代码通过228项回归。上传副本测试结果单独记录，不能因为软件测试通过就写成模型准确率。

## 可用工具

- `evaluation/test_suite.py`：模拟表达的离线规则指标。
- `evaluation/prepare_holdout.py`：按场景家族创建新的空白模板，不覆写已有模板。
- `evaluation/export_human_evaluation.py`：导出当前机器个人记录。
- `evaluation/benchmark_assistance.py`：本地固定请求对照。
- `evaluation/capture_precheck_cases.py`：保留第一遍模型输出、修正及用量。
- `evaluation/benchmark_paired_protocols.py`：两版已保存协议的交替调用。

需要本地Ollama、运行时数据库或之前版本的输入时应先准备实际依赖，不凭工具存在就当作实验完成。原完整模型提示、账号字段和个人数据库不在上传包中。
